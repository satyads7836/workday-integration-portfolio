\# OKTA – Core Connector Worker Integration



\## 🚀 Overview



Enterprise identity and access management integration between Workday and OKTA using Core Connector Worker (CCW), Workday Studio, and API-based provisioning workflows.



This integration automates employee lifecycle provisioning, role synchronization, account activation/deactivation, and workforce identity governance across enterprise systems.

\# 🔄 Integration Flow



1\. Worker lifecycle events triggered in Workday

2\. Core Connector Worker extracts employee data

3\. Studio transformation applies provisioning logic

4\. User provisioning data transmitted to OKTA

5\. OKTA synchronizes downstream application access

6\. Termination and role changes automatically updated
