\# SAP Fieldglass – Contingent Workforce Hiring Feed



\## 🚀 Overview



Enterprise-grade contingent workforce integration between Workday Recruiting and SAP Fieldglass for external workforce hiring, contractor onboarding, and workforce synchronization.



This integration automates contingent worker lifecycle processes while improving procurement visibility, onboarding efficiency, vendor coordination, and workforce compliance management.

\# 🔄 Integration Flow



1\. Contractor requisition created in Workday

2\. Workday sends hiring data to SAP Fieldglass

3\. Vendor onboarding workflow triggered

4\. Contractor worker profile synchronized

5\. Status updates returned to Workday

6\. Workforce compliance validations executed
