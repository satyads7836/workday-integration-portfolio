\# Workday Extend AI Chatbot – Employee Self Service Automation



\## 🚀 Overview



AI-powered employee self-service automation solution built using Workday Extend, conversational workflows, API integrations, and enterprise automation patterns.



This solution enables employees to perform HR actions through conversational interfaces including employment verification requests, payment election updates, leave balance inquiries, onboarding assistance, and policy guidance automation.
