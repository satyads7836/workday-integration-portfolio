# Screenshot Guidance

This folder is reserved for sanitized screenshots that support the portfolio narrative.

## Recommended Screenshots

- Agent Registry or agent overview
- Skill configuration showing execution mode
- Delegate Skill interaction access
- View Security for Agent Skill
- Ambient Skill configuration, if available
- Non-sensitive lifecycle or monitoring views

## Sanitization Checklist

Before committing a screenshot, remove or mask:

- Tenant and company names
- Tenant URLs
- Worker, candidate, and customer data
- User names and email addresses
- Security-group names that reveal an organization
- OAuth clients, secrets, tokens, keys, and certificates
- Internal IDs that can be traced to a real tenant
- Browser bookmarks, notifications, and unrelated applications

Use synthetic labels where context is required. Crop the image to the smallest relevant area and verify the final image at full resolution.

Do not commit a screenshot until a second review confirms that it contains no sensitive information.
